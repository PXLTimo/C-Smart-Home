# SmartHome Qt Project

## Requirements
- Qt 6.x (or Qt 5.15+)
- C++17 compatible compiler
- Qt Creator recommended

## Build instructions
1. Open Qt Creator
2. Open the `.pro` or CMake project
3. Configure with default kit
4. Build the project
5. Run the application

## Functionality
- Object-oriented SmartHome simulation
- Polymorphic devices
- Qt GUI interaction
- File logging
- Multithreading
- Signals & slots

## Tested on
- Windows 11
- Qt 6.7
